# Produal stand leads

Lead capture for the Produal stand at the Smart Buildings Show 2026 (ExCeL London, 14 to 15 October).

Three areas:

- Visitor sign-up: visitors enter their own details.
- Staff notes (PIN): the team adds a rating, next steps and notes to each visitor.
- Data & export (PIN): counts, breakdowns and a CSV export.

This copy stores leads in the browser on each device only. Export the CSV at the end of each day. On an iPad, add the page to the Home Screen from Safari's Share menu so it opens full screen and keeps its own storage.
